# حزمة شعار منصة هِمّة - إصدار المطوّر 1.0

هذه هي الحزمة المعتمدة للاستخدام في الموقع، وجميع الشعارات فيها **من دون العبارة التعريفية**.

## أي ملف يستخدم المبرمج؟

| الاستخدام | الملف الموصى به |
| --- | --- |
| الهيدر والقائمة الرئيسية | `assets/logo/svg/himma-logo-gradient.svg` |
| بديل أسرع ومتوافق جدًا | `assets/logo/svg/himma-logo-flat.svg` |
| خلفية داكنة | `assets/logo/svg/himma-logo-white.svg` |
| طباعة بلون واحد | `assets/logo/svg/himma-logo-navy.svg` |
| الأيقونة داخل الواجهة | `assets/mark/svg/himma-mark-gradient.svg` |
| Favicon | `assets/icons/favicon.svg` مع ملفات PNG وICO البديلة |
| أيقونة iPhone / iPad | `assets/icons/apple-touch-icon.png` |
| تطبيق ويب PWA | ملفات `pwa-*` و`pwa-maskable-*` |
| الطباعة أو الأرشفة | `assets/print/` بصيغتي PDF وEPS |

## تركيب سريع

1. انسخ مجلد `assets` إلى `public/assets/brand`.
2. انسخ وسوم ملف `developer/head-snippet.html` إلى عنصر `<head>`.
3. استورد `developer/brand-tokens.css` عند الحاجة إلى ألوان الهوية.

مثال:

```html
<img
  src="/assets/brand/logo/svg/himma-logo-gradient.svg"
  alt="منصة هِمّة"
  width="220"
  height="100"
>
```

## قواعد الاستخدام

- لا تضف السلوجن داخل ملف الشعار أو تحته تلقائيًا.
- لا تغيّر ترتيب الألوان أو نسب الشعار.
- لا تضف ظلالًا أو حدودًا أو مؤثرات إلى ملفات الشعار.
- اترك فراغًا حول الشعار يساوي تقريبًا قطر النقطة الصفراء.
- الحد الأدنى للشعار الأفقي رقميًا: 120 بكسل عرضًا.
- الحد الأدنى للرمز المنفرد رقميًا: 32 بكسل.
- استخدم `SVG` افتراضيًا؛ واستخدم `PNG` للأنظمة التي لا تدعم SVG.
