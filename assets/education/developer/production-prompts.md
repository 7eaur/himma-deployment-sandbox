# سجل إنتاج الصور

تم إنشاء الصور باستخدام أداة توليد الصور المدمجة، مع مراجع الأسلوب والشخصيات المعتمدة لمنصة هِمّة.

## قالب صور المفردات

Use case: scientific-educational
Asset type: Arabic grade-3 vocabulary picture
Primary request: one unmistakable subject matching the approved Himma educational cartoon style
Composition: centered square, full silhouette, generous padding
Background: flat chroma key for removal
Constraints: no text, no logo, no watermark, no unrelated objects

## قالب مشاهد الجمل

Use case: illustration-story
Asset type: sentence-comprehension scene
Composition: wide landscape, one clear action, low-detail background
Continuity: preserve approved child identity and Himma clothing
Constraints: no text, no caption, no speech bubbles, no ambiguous secondary action

## قالب صور التسلسل

Use case: illustration-story
Asset type: one card in a three-step sequence
Continuity: preserve character, clothing, objects, setting, lighting and camera angle
Change only the action and state required for the current step
Constraints: no number, no arrow, no text, no multiple steps in one image

## قالب صور القصص

Use case: illustration-story
Asset type: main story or assessment illustration
Composition: 16:9 story cover, balanced foreground and midground, responsive safe margins
Constraints: no text, no visual quiz answer, culturally respectful neutral Arabic setting
