# حزمة المحتوى المعتمد

`src/catalog.json` هو المرآة التنفيذية الوحيدة للمحتوى التعليمي المعتمد في هِمّة. المصدر الأكاديمي الأعلى يبقى ملف العميل الأصلي المحدد في `docs/specs/SOURCE_OF_TRUTH.md`، ويسجل الكتالوج بصمتي DOCX والنسخة النصية حتى لا يحدث اختلاف صامت.

## البنية

- 30 سؤالًا قبليًا بتوزيع مهاري 10/12/8.
- 30 سؤالًا بعديًا مكافئًا بالتوزيع نفسه.
- 10 أنشطة أساسية و5 أنشطة تقوية لكل مستوى.
- 44 مهارة قانونية ثابتة؛ يبقى اسم المهارة كما ورد في المصدر داخل `source_skill_name` وتُحفظ الخريطة الموحدة في `skill_id` و`skill_code`.
- كل نشاط يحتفظ بكل جولاته، لا بجولة نموذجية واحدة.
- الوسائط مرتبطة بمعرفات الـmanifest (`LET-03`, `VOC-01`, `STY-01`...) لا بأسماء ملفات عشوائية.

## التوليد والتحقق

```bash
python3 packages/content/scripts/compile_catalog.py
python3 packages/content/scripts/compile_catalog.py --check
python3 packages/content/scripts/validate_catalog.py
```

المترجم حتمي. وضع `--check` يفشل إذا عُدّل الناتج يدويًا أو تغير المصدر دون إعادة توليد. أداة التحقق تفحص الأعداد والتوزيع والمعرفات والمهارات والأنواع وبصمات المصدر ودلالة الصوت والصورة ووجود الملفات الفعلية.

إذا طلب المحتوى وسيطًا غير موجود في الحزمة الحالية، يجب تسجيله صراحة داخل `media_gaps` مع أثره. لا يجوز ربط أقرب ملف بالاسم أو استخدام صوت ينطق نصًا مختلفًا.

## البذر

`services/api/seed.py` يقرأ هذا الكتالوج فقط، ويحفظ النوع القانوني الكامل داخل `template_data`. يمنع البذر خلط كتالوج قديم مع الكتالوج المعتمد، كما يمنع تغيير بند سبق بذره دون ترحيل بيانات بإصدار مُراجع.
