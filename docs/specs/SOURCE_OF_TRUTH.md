# خريطة مصدر الحقيقة

تمنع هذه الخريطة اختيار مرجع بالاسم أو الرقم فقط عند وجود نسخ تاريخية متجاورة.

## ترتيب القوة العام

1. قرار مقبول ومؤرخ في `docs/ops/DECISIONS.md`.
2. المواصفات والحالة التشغيلية الحالية داخل `docs/specs/` و`docs/ops/`.
3. بيانات الحزم التنفيذية داخل `assets/`.
4. الوثائق الأصلية داخل `reference/original/`.
5. النسخ النصية المشتقة داخل `reference/derived/`.
6. لوحات العرض ونموذج الواجهة بوصفهما مرجعًا بصريًا وتفاعليًا فقط.

## الخريطة التنفيذية

| المجال | المصدر التنفيذي الحالي | دور الملفات الأخرى |
|---|---|---|
| اسم المنتج والهوية الأساسية | `.agents/rules/00-himma-core.md` و`assets/brand/ASSET_MANIFEST.json` | دليل الهوية الأصلي محفوظ للشرح والتاريخ؛ حزمة المطور هي مرجع الملفات القابلة للتطبيق. |
| نطاق المنتج والمنطق | `docs/specs/SYSTEM_SPEC.md` و`docs/specs/ACCEPTANCE_MATRIX.md` | وثيقتا 01 و05 للمحتوى والتفاصيل الأصلية. |
| المحتوى التعليمي التفصيلي | `reference/original/01_المحتوى_والتخطيط_المعتمد_لمنصة_همة.docx` | `packages/content/src/catalog.json` مرآة تنفيذية مولدة وحتمية تسجل بصمة الأصل؛ `01_المحتوى_والمرجع_العام...` مرجع تأسيسي داعم، ولا يعلو على القرار الأحدث. |
| الأصوات الجاهزة | `assets/audio/HIMMA_AUDIO_V1/manifest.csv` | وثيقتا 02 تحفظان قائمة التخطيط الأقدم؛ عدد 60 الوارد فيهما تجاوزه اعتماد حزمة V1 ذات 50 عنصرًا. |
| أهداف قراءة الطفل والتحليل | `reference/original/03_النصوص_المقروءة_وأهداف_التحليل_الصوتي.docx` | ملف القائمة الآخر مرجع مساعد للبحث السريع. |
| الصور التعليمية | `assets/education/ASSET_MANIFEST.json` وخرائط `assets/education/developer/` | وثيقتا 04 ولوحات العرض تشرحان الاستخدام ولا تستبدلان الملفات المنفصلة. |
| الشخصيات والشارات والأيقونات | `assets/characters/ASSET_MANIFEST.json` و`assets/characters/developer/asset-map.json` | لوحات الشخصيات مرجع بصري فقط. |
| تجربة الواجهة | `reference/ui-prototype/` للشكل والتفاعل فقط | لا يُعامل كمعمارية إنتاجية أو مصدر بيانات أو منطق مجال. |
| الحالة والتقدم | `docs/ops/STATUS.md` و`docs/ops/progress.json` | المحادثات ليست مصدر حقيقة. |

## قاعدة التعارض

لا يُحذف المرجع التاريخي ولا يُعدّل بصمت. عند تعارض يغيّر السلوك، يطبق القرار المقبول الأحدث، ويسجل أي قرار جديد في `DECISIONS.md`. إذا لم يوجد قرار يحسم الأثر، يضاف بند إلى `OPEN_ITEMS.md` عند نقطة الحاجة الفعلية.
