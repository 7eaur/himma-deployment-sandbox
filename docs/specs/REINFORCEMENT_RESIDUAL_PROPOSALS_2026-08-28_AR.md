# مقترحات سد الفجوات المتبقية في التقوية — M03

**الحالة:** PROPOSED — غير مفعلة في الكتالوج حتى اعتمادها.
**المرجع التربوي:** نفس التدرج المعتمد في كتاب التأهيل اللغوي المستخدم سابقًا في المشروع: القراءة بالسكون، ثم الطلاقة والاستيعاب القرائي. لا يتم نسخ تمارين الكتاب حرفيًا؛ المحتوى أدناه أصلي لمنصة هِمّة ومبني على نفس التسلسل المهاري.

## 1) L2-REIN-12 — ثبّت السكون

- المستوى: 2 — بناء الكلمة.
- المهارة: قراءة كلمات السكون.
- العائلة: `sukoon`.
- نوع التفاعل: `choose_one`.
- الهدف: تمييز موضع السكون بصريًا قبل الرجوع إلى نشاط القراءة الأساسي للتحقق الصوتي.
- النجاح: 4/5 فأعلى.
- بعد النجاح: العودة إلى النشاط الأساسي الذي كشف ضعف السكون وإعادة الجزء الضعيف.

الجولات:

1. اختر الكلمة المكتوبة بالسكون الصحيح:
   - مَكْتَب ✅
   - مَكَتَب

2. اختر الكلمة المكتوبة بالسكون الصحيح:
   - شَمْس ✅
   - شَمَس

3. اختر الكلمة المكتوبة بالسكون الصحيح:
   - نَجْم ✅
   - نَجَم

4. اختر الكلمة المكتوبة بالسكون الصحيح:
   - بَحْر ✅
   - بَحَر

5. اختر الكلمة المكتوبة بالسكون الصحيح:
   - يَكْتُب ✅
   - يَكَتُب

**وسائط جديدة:** لا يحتاج ملفًا صوتيًا ثابتًا. التحقق النهائي يكون بالعودة إلى Core Reading عندما يصبح التسجيل مطلوبًا؛ وفي وضع التخطي الصوتي الحالي يبقى محايدًا.

## 2) L3-REIN-11 — ابحث عن الإجابة في النص

- المستوى: 3 — الطلاقة والفهم.
- المهارة: الفهم المباشر.
- العائلة: `literal_comprehension`.
- نوع التفاعل: `choose_one`.
- النجاح: 4/5 فأعلى.
- الهدف: تدريب الطالب على استخراج معلومة مذكورة صراحة في نص قصير، دون استنتاجات إضافية.

النص:

> ذَهَبَ سَالِمٌ مَعَ أَخِيهِ إِلَى الْحَدِيقَةِ صَبَاحًا. أَخَذَا مَعَهُمَا كُرَةً وَزُجَاجَةَ مَاءٍ. لَعِبَا قُرْبَ الشَّجَرَةِ، ثُمَّ جَلَسَا لِلرَّاحَةِ. قَبْلَ الْعَوْدَةِ جَمَعَا أَغْرَاضَهُمَا وَتَرَكَا الْمَكَانَ نَظِيفًا.

الأسئلة:

1. مع من ذهب سالم إلى الحديقة؟
   - مع أخيه ✅
   - مع معلمه
   - وحده

2. متى ذهبا إلى الحديقة؟
   - صباحًا ✅
   - ليلًا
   - بعد المغرب

3. ماذا أخذا معهما؟
   - كرة وزجاجة ماء ✅
   - كتابًا وحقيبة
   - طعامًا فقط

4. أين لعبا؟
   - قرب الشجرة ✅
   - داخل البيت
   - في المكتبة

5. ماذا فعلا قبل العودة؟
   - جمعا أغراضهما ✅
   - تركا الكرة
   - اشتريا كتابًا

**وسائط جديدة:** لا يحتاج صورًا أو أصواتًا إلزامية.

## 3) L3-REIN-12 — رتّب الجملة

- المستوى: 3 — الطلاقة والفهم.
- المهارة: بناء الجملة.
- العائلة: `sentence_structure`.
- نوع التفاعل: `sequence`.
- النجاح: 4/5 فأعلى.
- الهدف: ترتيب كلمات جملة عربية صحيحة بصورة تدريجية، مع جمل أطول قليلًا من تقوية المستوى الثاني.

الجولات:

1. الكلمات:
   - يَقْرَأُ / سَالِمٌ / الْكِتَابَ
   - الصحيح: يَقْرَأُ سَالِمٌ الْكِتَابَ.

2. الكلمات:
   - زَرَعَتْ / مَرْيَمُ / زَهْرَةً / جَمِيلَةً
   - الصحيح: زَرَعَتْ مَرْيَمُ زَهْرَةً جَمِيلَةً.

3. الكلمات:
   - يَلْعَبُ / الْأَطْفَالُ / فِي / الْحَدِيقَةِ
   - الصحيح: يَلْعَبُ الْأَطْفَالُ فِي الْحَدِيقَةِ.

4. الكلمات:
   - شَرِبَ / خَالِدٌ / الْمَاءَ / بَعْدَ / اللَّعِبِ
   - الصحيح: شَرِبَ خَالِدٌ الْمَاءَ بَعْدَ اللَّعِبِ.

5. الكلمات:
   - أَعَادَ / الطَّالِبُ / الْكِتَابَ / إِلَى / الْمَكْتَبَةِ
   - الصحيح: أَعَادَ الطَّالِبُ الْكِتَابَ إِلَى الْمَكْتَبَةِ.

**وسائط جديدة:** لا يحتاج صورًا أو أصواتًا.
