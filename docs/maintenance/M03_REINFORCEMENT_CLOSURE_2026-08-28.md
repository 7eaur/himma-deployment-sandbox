### 2. ربط الضعف بالتقوية
- تم بناء عقد deterministic يغطي المهارات الـ44 ويحوّل كل مهارة إلى عائلة مهارية ثم إلى المرشحات المعتمدة داخل المستوى نفسه.
- لا يوجد اختيار عشوائي.
- لا توجد تقوية من مستوى مختلف.
- عدم وجود تغطية معتمدة يؤدي إلى safe hold / supervisor review وليس إلى محتوى غير ذي صلة.

### 3. دورة التقوية المستمرة
العقد التنفيذي المعتمد الآن:

`ضعف في خطوة أساسية → تحديد المهارة/العائلة → نشاط تقوية معتمد → إكمال التقوية → إعادة فتح المحاولة الأساسية نفسها → إعادة الخطوة/الخطوات الضعيفة → تحقق → متابعة`

- يتم حفظ الدورة في `reinforcement_cycles`.
- يتم حفظ مصدر الضعف `source_attempt_id` و`source_step_ids`.
- بعد إكمال التقوية لا يبدأ نشاط أساسي عشوائي؛ يعود الطالب إلى موضع الضعف المسجل.
- نجاح التحقق يغلق الدورة بحالة `verified`.
- الفشل المتكرر لا يصنع حلقة لا نهائية؛ تتحول الدورة إلى `escalated` للمراجعة البشرية.
- الدورة النشطة أو المصعّدة تمنع إعادة تقييم تكيفي متعارض قبل حلها.

### 4. الحياد الأكاديمي للاستثناءات المؤقتة

- 105 أصلية.
