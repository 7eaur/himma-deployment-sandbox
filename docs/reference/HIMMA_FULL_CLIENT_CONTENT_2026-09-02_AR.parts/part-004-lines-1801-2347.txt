التقويات الإضافية المعتمدة للمستوى الثالث

L3-REIN-06 — اقرأ الكلمات بهدوء
المهارة: دقة قراءة الكلمات.
الجولات: كِتَاب — مَدْرَسَة — نَخْلَة — عُصْفُور — مُعَلِّم.

L3-REIN-07 — سباق الكلمات الهادئ
المهارة: سرعة قراءة الكلمات مع الدقة.
ملاحظة: الوقت يحسب داخليًا ولا يظهر للطفل.
الجولة 1: باب — قلم — شمس — كتاب — نخلة.
الجولة 2: مدرسة — حديقة — عصفور — معلم — حقيبة.
الجولة 3: يلعب — يقرأ — يكتب — يجلس — يذهب.

L3-REIN-08 — فقرة أقصر للطلاقة
المهارة: طلاقة قراءة النص.
النص:
«ذَهَبَ سَالِمٌ إِلَى الْحَدِيقَةِ. رَأَى عُصْفُورًا فَوْقَ شَجَرَةٍ. جَلَسَ قَلِيلًا، ثُمَّ عَادَ إِلَى الْبَيْتِ.»
ملاحظة: الوقت يحسب داخليًا ولا يظهر للطفل.

L3-REIN-09 — معنى الكلمة من الجملة
المهارة: المفردات من السياق.
الجولات:
1. «جَلَسَ خَالِدٌ قُرْبَ الْبَابِ.» ما معنى «قُرْبَ»؟ — بجانب / بعيدًا / خلف — الإجابة: بجانب.
2. «كَانَ الْمَكَانُ هَادِئًا.» ما معنى «هادئًا»؟ — قليل الضوضاء / مزدحمًا / سريعًا — الإجابة: قليل الضوضاء.
3. «أَعَادَ سَالِمٌ الْكِتَابَ.» ما معنى «أعاد»؟ — أرجع / أخذ / كسر — الإجابة: أرجع.
4. «الْمَاءُ صَافٍ.» ما معنى «صافٍ»؟ — نظيف وواضح / مظلم / ساخن — الإجابة: نظيف وواضح.
5. «جَمَعَ الْأَطْفَالُ الْمُخَلَّفَاتِ.» ما المقصود بـ«المخلفات»؟ — الأشياء المتروكة بعد الاستخدام / الألعاب / النباتات — الإجابة: الأشياء المتروكة بعد الاستخدام.

L3-REIN-10 — ماذا حدث أولًا؟
المهارة: ترتيب أحداث النص.
الجولات:
1. «أَخَذَ سَالِمٌ الْكِتَابَ، ثُمَّ قَرَأَهُ.» — الترتيب: أخذ الكتاب ← قرأ الكتاب.
2. «زَرَعَتْ مَرْيَمُ بَذْرَةً، ثُمَّ سَقَتْهَا.» — الترتيب: زرعت البذرة ← سقتها.
3. «دَخَلَ خَالِدٌ الْمَكْتَبَةَ، وَقَرَأَ كِتَابًا، ثُمَّ أَعَادَهُ.» — دخول المكتبة ← القراءة ← إعادة الكتاب.
4. «ذَهَبَ مَاجِدٌ إِلَى الشَّاطِئِ، وَلَعِبَ بِالرَّمْلِ، ثُمَّ نَظَّفَ مَكَانَهُ.» — ذهب ← لعب ← نظف.
5. «غَسَلَتْ هِنْدٌ التُّفَّاحَةَ، ثُمَّ قَطَّعَتْهَا، وَبَعْدَ ذَلِكَ أَكَلَتْهَا.» — غسلت ← قطعت ← أكلت.

L3-REIN-11 — أجب من النص
المهارة: الفهم المباشر واستخراج معلومة صريحة من الجملة.
الجولات:
1. «ذَهَبَ سَالِمٌ إِلَى الْمَدْرَسَةِ صَبَاحًا.» أين ذهب سالم؟ — إلى المدرسة / إلى الحديقة / إلى السوق — الإجابة: إلى المدرسة.
2. «حَمَلَ مَاجِدٌ حَقِيبَتَهُ وَخَرَجَ مِنَ الْبَيْتِ.» ماذا حمل ماجد؟ — حقيبته / كتابًا / كرة — الإجابة: حقيبته.
3. «قَرَأَ خَالِدٌ كِتَابًا فِي الْمَكْتَبَةِ.» من قرأ الكتاب؟ — خالد / سالم / ماجد — الإجابة: خالد.
4. «سَقَتْ هِنْدٌ الزَّهْرَةَ بِالْمَاءِ.» ماذا سقت هند؟ — الزهرة / الشجرة / العشب — الإجابة: الزهرة.
5. «لَعِبَ مَاجِدٌ بِالْكُرَةِ فِي الْحَدِيقَةِ.» بماذا لعب ماجد؟ — بالكرة / بالرمل / بالكتاب — الإجابة: بالكرة.

L3-REIN-12 — رتّب كلمات الجملة
المهارة: بناء الجملة وترتيب كلماتها.
الجولات الصحيحة:
1. يقرأ ← سالم ← الكتاب.
2. يلعب ← ماجد ← بالكرة.
3. تسقي ← هند ← الزهرة.
4. فتح ← خالد ← الباب.
5. ذهب ← سالم ← إلى المدرسة.
