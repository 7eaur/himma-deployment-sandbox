# البنود المفتوحة

حُسم OI-01 الخاص بعدد الأصوات في ADR-003، وحُسم OI-09 الخاص بالصف الدراسي وسجل الطالب في ADR-010. كما حُسم أسلوب التعامل مع فجوات ربط التقوية في ADR-012 دون اختراع محتوى جديد.

| المعرّف | البند | هل يوقف البناء؟ | نقطة الحسم |
|---|---|---:|---|
| OI-02 | مزود/وحدة التحليل الصوتي وعقدها، وحسم الانتقال من المراجعة البشرية الحالية إلى التحليل الآلي الذي طلبه العميل | لا يوقف إغلاق Recovery؛ نعم لإغلاق P07 الحقيقي | قبل إضافة Adapter إنتاجي أو اعتماد P07 |
| OI-03 | حد الثقة وإصدار المعايرة | لا يوقف Recovery؛ نعم للقرار الصوتي الآلي | بعد معايرة أصوات ممثلة وقبل الدراسة |
| OI-04 | مدة التدخل وعدد الجلسات ومدتها | لا؛ إعداد قابل للتثبيت | قبل تفعيل الدراسة |
| OI-05 | مدة الاحتفاظ بتسجيلات الأطفال | لا للبناء؛ نعم للإطلاق | قبل تخزين بيانات أطفال حقيقية في الإنتاج |
| OI-06 | الدومين وحسابات الاستضافة | لا للبناء؛ نعم للنشر | مرحلة النشر |
| OI-07 | بيانات وشعارات الجهة المشرفة | لا | قبل اعتماد التقارير النهائية |
| OI-08 | نُقّحت القيم المكشوفة من الشجرة الحالية، لكن يجب تدوير أي قيمة استُخدمت فعليًا لأن التاريخ العام قد يحتوي النسخة السابقة | لا يوقف baseline بقيم اختبار جديدة؛ يوقف الإنتاج والنشر | قبل أي نشر أو إعادة استخدام لبيئة الجهاز |

## ما ليس بندًا مفتوحًا بعد Recovery

- تسمية الواجهة «المشرف» محسومة؛ `researcher` معرف توافق داخلي فقط (ADR-011).
- عدم وجود تطابق آلي لبعض أنشطة التقوية ليس مبررًا لاختيار نشاط عشوائي؛ مسار المراجعة اليدوية المعتمد محسوم (ADR-012).
- الصور التعليمية الحالية ومسارات الوسائط المستخدمة في السيناريو المختبر أصبحت موصولة فعليًا وتم اختبار bytes حقيقية.
- أُغلق OI-10 في ADR-013 بعد إدخال الأصلين المعتمدين `WRD-29` («موز») و`SYL-13` («سَا») وربطهما دون بدائل دلالية.

لا تسأل المستخدم عن البنود المفتوحة في كل مرحلة. ارجع إلى الجدول واطلب القرار فقط عند نقطة الحسم الفعلية.
