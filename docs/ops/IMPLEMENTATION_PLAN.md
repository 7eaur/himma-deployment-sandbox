# خطة التنفيذ المعتمدة لمنصة هِمّة

تم اعتماد نتيجة المرحلة صفر وتحديث الخطة وفق المتطلبات الموثقة، لتكون المرجع الملزم للتنفيذ.

## 1. ثوابت الأصول والمراجع (ADR-003)
- المعتمد النهائي للأصوات هو 50 عنصرًا صوتيًا، ولكل عنصر ملف WAV و MP3 (إجمالي 100 ملف فعلي).
- نصوص التعليمات العشرة القديمة ليست ملفات ناقصة.
- يُعتمد حصرًا على الأصول الإنتاجية الموثقة في الـ `manifests` داخل مجلد `assets`. لا يُستخدم مجلد `reference/ui-prototype` أو لوحات العرض كأصول أو كود إنتاجي بتاتاً.

## 2. تسلسل المراحل والنطاق

### المرحلة 1: النواة والأمن
تأسيس البنية التحتية لهيكل Monorepo والذي يشمل كامل النطاق التالي:
- **apps/web**: الواجهات الأمامية.
- **services/api**: واجهات برمجة التطبيقات (API).
- **services/worker**: هيكل تشغيلي فقط (بدون مزود ASR وهمي).
- **packages/contracts**: عقود OpenAPI وعميل TypeScript.
- **packages/content**: إدارة المحتوى.
- **قواعد البيانات والتخزين**: PostgreSQL، Redis، وتخزين خاص متوافق مع S3.
- **تجهيزات تشغيلية**: Docker Compose، Alembic، CI، فحوصات health/readiness، ملف `env.example` (دون أسرار)، وسجل تدقيق (Audit Log).
- **المصادقة والأمن**:
  - دخول آمن للباحثة.
  - رموز دخول آمنة وقابلة للإلغاء والتجديد للطلاب.
  - تطبيق الصلاحيات بشكل صارم داخل الـ API.
  - استخدام كوكيز `Secure HttpOnly SameSite`.
  - إنشاء 15 طالبًا ضمن قاعدة بيانات حقيقية، مع منع استخدام أي بيانات أطفال حقيقية.
- **بوابة القبول**: AC-01، AC-02، والأساس التشغيلي من AC-15 (مع اختبارات Backend, Frontend, Integration, و E2E حقيقية).

### المرحلة 2: مسار الطالب ومراجعة الباحثة
- استيراد المحتوى المعتمد: 60 سؤالًا (30 قبليًا و30 بعديًا) و45 نشاطًا (10 أساسية و5 تقوية لكل مستوى). تُطبّق أنشطة التقوية التعليمية هنا وفي المرحلة 3.
- **القراءة الصوتية**: يمنع منعاً باتاً منح درجات وهمية للأنشطة الصوتية.
- تُسجّل الأصوات وتُحفظ في التخزين الخاص ثم تُحوّل لمراجعة الباحثة. لا يكتمل الاختبار القبلي ولا يوزّع المستوى إلا بعد مراجعة واعتماد الأسئلة الصوتية.

### المرحلة 3: محرك التكيف والمكافآت
- تطبيق الأوزان 50/30/20 على آخر 3 محاولات صالحة: 50% للأحدث، 30% للسابقة، 20% للثالثة.
- لا تدخل المحاولات الفاشلة أو ذات الثقة المنخفضة في القرار الأكاديمي.
- إدارة الترقيات والمستويات استناداً لحساب الأوزان.

### المرحلة 4: التحليل الصوتي الحقيقي (ASR)
- دمج مزود ASR الآلي مع الـ Worker للتحليل التلقائي السريع.
- الإبقاء على خط المراجعة البشرية (للباحثة) حصراً للحالات والتسجيلات ذات الثقة المنخفضة.

### المرحلة 5: البعدي، لوحة الباحثة والتقارير
- تفعيل الاختبار البعدي بناءً على تقدم الطالب وموافقة الباحثة.
- واجهات لوحة الباحثة والتقارير والبيانات التفصيلية.
- تصدير السجلات والتقارير بصيغتي Excel و PDF.

### المرحلة 6: التقوية التشغيلية والإطلاق
- التقوية الأمنية والتشغيلية الإضافية، تحسين الوصولية.
- اختبارات E2E النهائية الشاملة.
- إجراءات النسخ الاحتياطي وإطلاق النشر المعتمد.
