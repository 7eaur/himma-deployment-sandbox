# خط أساس المستودع النهائي

## التعريف

- المنتج: منصة هِمّة التعليمية.
- الإصدار: `1.1.0 FINAL`.
- تاريخ الإقفال: 6 أغسطس 2026.
- مرجع الحسم: `docs/specs/SOURCE_OF_TRUTH.md`.
- حالة الحزمة: جاهزة لتسليمها إلى فريق التنفيذ وبدء مرحلة الجرد صفر.

## الجرد المتحقق

- 638 ملفًا شاملًا ملف البصمات النهائي وهذا التقرير.
- 48 مدخلًا في حزمة العلامة والشعار.
- 143 مدخلًا في حزمة الشخصيات والشارات والأيقونات.
- 193 مدخلًا في حزمة الصور التعليمية، وتشمل الأصول وخرائط الربط والنسخ المحسنة للويب.
- 173 صورة PNG، و168 صورة WebP، و81 ملف SVG، وملف ICO واحد؛ فُتحت جميع الصور أو حُللت بنيتها بنجاح.
- 10 مستندات Word أصلية؛ فُحصت بنيتها، ورُسمت صفحاتها الـ139 وفُحصت بصريًا دون تلف أو قص أو تداخل.
- لا توجد ملفات صفرية، أو روابط رمزية مكسورة، أو تعارضات أسماء غير حساسة لحالة الأحرف، أو مجلدات بناء واعتماد مولدة داخل التسليم.

## الصوت المعتمد في V1

- 50 معرفًا صوتيًا معتمدًا في `assets/audio/HIMMA_AUDIO_V1/manifest.csv`.
- 50 ملف WAV رئيسيًا: PCM 16-bit، أحادي القناة، 24 kHz.
- 50 ملف MP3 للاستخدام داخل الويب: أحادي القناة، 24 kHz.
- المدة الإجمالية: 171.640 ثانية؛ أقصر ملف 0.560 ثانية وأطول ملف 5.304 ثانية.
- التوزيع: 4 تغذية راجعة، و6 أصوات حروف، و12 مقطعًا، و28 كلمة.
- النص التاريخي الذي ذكر 60 ملفًا كان يضم 10 تسجيلات تعليمات `INS-01` إلى `INS-10`. الحزمة الثنائية المعتمدة لـV1 تحتوي 50 أصلًا، ولا تُعد ملفات التعليمات العشرة مفقودة في هذا الإصدار ولا يجوز توليدها دون قرار وحزمة جديدة.

## الكود المرجعي

- نسخة الواجهة تحت `reference/ui-prototype` مرجع واجهات قابل للبناء والاختبار، وليست منصة الإنتاج المكتملة.
- تم تحديث `next` و`eslint-config-next` إلى `16.3.0` وإعادة توليد ملف القفل لإغلاق التنبيهات الأمنية المكتشفة في النسخة السابقة.
- نجح التثبيت النظيف المعزول مع تعطيل سكربتات `postinstall` في بيئة الفحص فقط، ثم البناء، ثم اختبار HTML المرسوم: اختبار واحد ناجح دون فشل.
- نتيجة `npm audit --omit=dev`: صفر ثغرات معلنة في اعتماديات الإنتاج (0 منخفضة، 0 متوسطة، 0 عالية، 0 حرجة).

## سلامة التسليم

- تطابق كل مسار وحجم وبصمة SHA-256 في بيانات حزم العلامة والشخصيات والصور مع الملف الفعلي.
- اجتاز كل ملف WAV وMP3 فحص `ffprobe` وفك الترميز عبر `ffmpeg`.
- اجتازت ملفات JSON وDOCX والصور فحوص القراءة والبنية.
- لا تتضمن الحزمة `node_modules` أو مخرجات بناء أو ملفات `.env` أو أسرارًا أو تسجيلات أطفال.
- ملف `REPOSITORY_MANIFEST.sha256` هو سجل البصمات النهائي ويُتحقق منه بالأمر:

  ```bash
  sha256sum -c REPOSITORY_MANIFEST.sha256
  ```

## ملاحظات تشغيلية

- ملفات Word الأصلية محفوظة دون إعادة تأليف. عند اختلاف مرجع تاريخي مع الأصول الحالية، يُطبّق ترتيب الأولوية في `docs/specs/SOURCE_OF_TRUTH.md`.
- لا يحتوي ZIP على مجلد `.git` حتى لا تتضاعف الأصول الثنائية. بعد فك الضغط يُشغّل `bash scripts/init-git.sh` لإنشاء مستودع Git وعمل baseline commit.
- القرارات المفتوحة في `docs/ops/OPEN_ITEMS.md` تخص الإطلاق والإنتاج ولا تمنع Antigravity من بدء مرحلة الجرد والمعمارية.
