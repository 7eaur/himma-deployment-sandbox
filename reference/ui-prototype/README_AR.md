# كود النموذج التفاعلي لواجهات منصة هِمّة

هذه الحزمة هي النسخة المصدرية الكاملة للنموذج التفاعلي المنشور لمنصة **هِمّة**. تُسلَّم للمطور كمرجع معتمد للاتجاه البصري، القوالب، توزيع العناصر، وأسلوب تجربة الطالب والباحثة.

> مهم: هذا نموذج واجهات تفاعلي، وليس النسخة الإنتاجية الكاملة للمنصة. بيانات الطلاب، تسجيل الدخول، التسجيل الصوتي، تحليل النطق، التقارير، والتصدير ما زالت محاكاة داخل الواجهة وتحتاج إلى ربط خلفي حقيقي.

## الشاشات الموجودة

- شاشة الترحيب.
- دخول الطالب بالرمز.
- لوحة الطالب ومسار المستويات.
- نموذج من الاختبار القبلي.
- نموذج نشاط تعليمي تفاعلي.
- شاشة تسجيل القراءة والتحليل التجريبي.
- شاشة النجاح والمكافآت.
- دخول الباحثة.
- لوحة الباحثة، الطلاب، التقارير، والتسجيلات.

## أهم المسارات

- `app/page.tsx`: جميع الشاشات والتفاعلات التجريبية.
- `app/globals.css`: نظام التصميم الكامل، الألوان، المقاسات، والتجاوب.
- `app/layout.tsx`: إعداد الصفحة والخطوط والاتجاه العربي.
- `public/himma/`: الشعار، الشخصيات، الصور التعليمية، الأيقونات، المستويات، والمكافآت.
- `public/fonts/`: الخطوط العربية المحلية.
- `package.json`: الحزم وأوامر التشغيل والبناء.

## التشغيل محليًا

المتطلبات:

- Node.js إصدار `22.13.0` أو أحدث.
- npm.

الأوامر:

```bash
npm ci
npm run dev
```

ثم افتح العنوان الذي يظهر في نافذة التشغيل.

## فحص نسخة الإنتاج

```bash
npm run build
npm run validate:artifact
```

## ما يجب على المطور الحفاظ عليه

- اتجاه الواجهة `RTL` كاملًا.
- شاشة الطفل تركز على مهمة واحدة وزر رئيسي واحد.
- النص العربي كبير وواضح ومريح لصعوبات القراءة.
- هوية هِمّة: الأزرق كلون أساسي، الأصفر للتشجيع، والأخضر للنجاح.
- استخدام الشخصيات والأصول الموجودة دون استبدالها بصور عشوائية.
- فصل واجهة الطالب الهادئة عن لوحة الباحثة الأكثر كثافة، مع بقاء الهوية موحدة.

## المطلوب عند تحويل النموذج إلى منصة فعلية

1. فصل الشاشات إلى صفحات ومكوّنات مستقلة قابلة للصيانة.
2. ربط تسجيل الدخول وقاعدة بيانات الطلاب والباحثة.
3. تنفيذ الاختبارين القبلي والبعدي ومنطق المستويات والتكيف.
4. ربط التسجيل الصوتي والتحليل الحقيقي بدل المحاكاة.
5. ربط الأنشطة والصور والأصوات من خرائط المحتوى المعتمدة.
6. بناء التقارير والتصدير إلى PDF وExcel من بيانات حقيقية.
7. إضافة الصلاحيات، الحماية، النسخ الاحتياطي، وسجل التقدم.

## تنبيه للمطور

لا يُعتمد النص أو الرقم التجريبي الظاهر داخل النموذج كبيانات نهائية. المرجع الوظيفي والتعليمي الأساسي هو حزمة **تخطيط وتحليل هِمّة**، بينما هذه الحزمة مرجع تصميم وتجربة استخدام وقوالب واجهات.
