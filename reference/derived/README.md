# Derived machine-readable references

These Markdown files were deterministically extracted from the supplied DOCX references to reduce repeated binary-document parsing and context cost.

- They preserve the source wording but may not preserve Word layout, embedded images, or callout styling.
- Use them for search and exact text/content lookup.
- Use `reference/original/` DOCX/PDF for visual/layout verification and final authority when extraction is ambiguous.
- Do not edit these files as a way to change the approved specification. Record a decision and update the authoritative source/version instead.
- These files preserve historical wording and may contain superseded counts or status labels. Resolve current precedence through `docs/specs/SOURCE_OF_TRUTH.md`; for prerecorded audio, the approved `assets/audio/HIMMA_AUDIO_V1/manifest.csv` overrides older file-02 counts.
